Ajuda da Mesa de RPG

Jogadores

Abre uma janela só com o mapa e os tokens, sincronizada em tempo real. Arraste-a para o segundo monitor.

Mapa

Importar imagem: Clique para carregar um mapa em qualquer formato de imagem.

Tamanho do mapa: Redimensione o mapa de 10% a 400%.

Grid

Mostrar grid: Ativa/desativa a visualização da grade de células.

Tamanho da célula: Ajuste o tamanho da célula de 16 a 128 pixels.

Cor: Altere a cor da grade usando o seletor de cores.

Névoa de Guerra

Desenhar oclusão: Ativa o modo de desenho. Com o modo ativo, arraste no mapa para criar um retângulo preto que oculta a área para os jogadores.

No mestre: Os retângulos aparecem semi-transparentes para você ver através.

Remover: Clique com o botão direito sobre um retângulo para removê-lo.

Limpar tudo: Remove todos os retângulos de oclusão de uma vez.

Tokens

Adicionar token: Cria um novo token no centro da visão.

Scroll: Zoom in/out (ancorado no cursor).

Botão do meio: Arrasta o mapa (pan).

Botão esquerdo: Arrasta tokens pelo mapa.

Botão direito: Remove um token.

Duplo clique: Abre o editor do token (nome, foto, cor).

Clique na lista: Clique em um token na lista lateral para editar.

Token de jogador: Marque a caixa "Token de jogador (Party)" ao criar/editar para adicioná-lo à Party.

Party

O que é: Tokens marcados como jogador aparecem no painel Party. Todos começam com uma barra de Vida.

Barras universais: As barras (Vida, Mana, Sanidade…) são compartilhadas por toda a party — se você criar uma barra, todos os membros passam a tê-la. Use "+ Nova barra universal" no topo do painel.

Editar/Remover barra: Os ícones ✎ e ✕ nos chips do topo editam o nome/cor ou removem a barra de todos.

Valores por membro: Cada membro tem seu próprio atual/máximo. Clique no ✎ da barra dentro do card do membro para ajustar só os valores dele.

Barras ativas no mapa: Marque a caixa ao lado de uma barra no topo do painel para exibi-la no mapa. No máximo 2 podem estar ativas ao mesmo tempo.

Exibição: No editor da barra, escolha o modo: Horizontal (acima do token), Vertical (à esquerda ou direita, com orientação para cima/baixo) ou Radial (anel de progresso ao redor do token). Vertical e horizontal permitem inverter a orientação (→ ou ←).

No mapa: As barras ativas aparecem em cada token de jogador, sincronizadas com a tela do jogador.

Combate

Iniciar combate: Começa o rastreamento de turno. Os tokens aparecem na barra de combate na ordem atual.

Próximo turno: Avança o turno para o próximo token na ordem.

Reordenar: Arraste tokens na barra de combate para mudar a ordem de iniciativa.

Encerrar: Para o rastreamento de combate.

Controles de Câmera

Botões de zoom: Use os botões no canto inferior direito para aumentar, diminuir ou resetar o zoom.

Wheel zoom: Use a roda do mouse no mapa para fazer zoom (ancorado no cursor).

Pan: Mantenha o botão do meio pressionado e arraste para mover a câmera.
